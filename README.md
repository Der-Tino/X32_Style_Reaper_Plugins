# X32_Style_Reaper_Plugins

Contents:
JSFX Reaper Plugins modeled after the classic Behringer X32 Effects

| Plugin | X32 Effekt | Inhalt |
|---|---|---|
| `X32_Combinator.jsfx` | Combinator | 5-Band-Multiband-Kompressor (ohne SBC) |
| `X32_PrecisionLimiter.jsfx` | Precision Limiter | Limiter mit Lookahead, Squeeze, Autogain |
| `X32_TubeStage.jsfx` | Tube Stage / Overdrive | Röhrensättigung (Even/Odd), Lo/Hi Cut, Bass/Treble-Shelving |

Die Plugins bilden Bedienung und Parameterbereiche der X32-Effekte nach, sind aber keine Klone des Original-DSP.

Installation:
Copy into REAPER RESOURCE PATH / Effects

On Win: %APPDATA%\REAPER\Effects
